MENDEZ / TAGAYTAY ⇄ ONE AYALA
NOTICE BOARD
Shown as a banner at the top of everyone's tracker. Good for schedule changes, service alerts, or "still testing" notes. One notice at a time.
OPERATING HOURS Departure windows and headway. Changed once a season.
Departure windows from each end. Add a second window for split schedules like the March 2026 poster. The app treats buses as possibly en route for 3.5 hours after each window closes.
WATCHING NOW
Devices with the tracker page open in the last 3 minutes, including anyone sharing with the app in front of them. Anonymous: each tab makes up a random ID, it is never linked to a person, and it is deleted 3 minutes after the tab closes. Nothing is kept, so there is no history to look back at.
Honest limit: this counts open tabs, not people. One person with the map open on two devices is two, and because watching needs no key, anyone who worked out the call could inflate it with made-up IDs. Read it as a rough sense of demand, not a headcount.
LIVE SHARERS
Everyone currently sharing a bus position. Stopping one removes the bus and blocks that phone from sharing for 6 hours, and their app tells them an organizer stopped it.
Honest limit: someone determined can reload the page to get a new session and share again. Changing the share key below is the only real expulsion, and it affects everyone.
STOPPED SHARERS
Blocked from sharing until the time shown. Tap Allow again if you stopped someone by mistake.
SIGHTINGS
Posted by anyone, no key needed. Delete spam here; the rest expire on their own.
Honest limit: this hides the board, it does not lock it. Posting needs no key, so somebody who worked out the call could still add one while it is switched off. Riders would never see it and it expires on its own, but it would still turn up in this list.
PASKO
FRESHNESS + LIMITS How long a bus and a sighting live, and the abuse cap.
SHARE KEY Rotate the key that lets people share from the bus.
The key that lets people share from the bus. Changing it: anyone already sharing gets 4 hours to finish their trip, and NEW sharers need the new key immediately. The old links in the group chat stop working for starting a share, so post the new link after changing.
ADMIN KEY Change the key for this page. Cannot be recovered.
Changes the key for THIS page. Write the new one down before saving; it is stored only as a hash and cannot be recovered, only reset directly in Supabase.
Signing out only forgets the key on this device.
